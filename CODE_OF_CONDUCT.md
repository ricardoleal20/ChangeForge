# Code of conduct

This project welcomes contributions regardless of background, experience, gender identity, race, religion, disability or other personal characteristics.

Treat contributors respectfully. Give constructive technical feedback, accept good-faith corrections, and focus discussions on the work. Harassment, threats, discrimination, sexualized conduct and publishing other people's private information are not acceptable.

This policy applies to project issues, pull requests and other project-maintained spaces. Maintainers may edit or remove inappropriate content, warn participants, or restrict participation according to the severity and repetition of the behavior.

Report conduct concerns privately to the maintainer at **rick.leal420@gmail.com**. Include relevant links and context; reports will be handled privately to the extent practical. Security vulnerabilities should use the separate [security reporting channel](SECURITY.md).

# Contributing to ReleaseWeave

Thank you for contributing. The complete [contributor guide](docs/CONTRIBUTING.md) covers local setup, tests, changesets and pull requests.

Start with an existing issue, or open a bug report or feature proposal before substantial changes. Small fixes and documentation improvements can go directly to a pull request. Follow the [code of conduct](CODE_OF_CONDUCT.md). Report vulnerabilities through the [security policy](SECURITY.md), rather than public issues.

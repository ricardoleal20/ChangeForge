ReleaseWeave is a Rust CLI for single repositories and monorepos. Record changes, preview independent package versions, and prepare changelogs and GitHub releases.

Get Started GitHub

What is ReleaseWeave?

Record each change in a TOML changeset. ReleaseWeave computes the highest requested bump per package, updates only affected manifests, and records package-specific notes and tags. Preview the result locally before a GitHub release PR is merged.

Quick Start

Get up and running with ReleaseWeave in just a couple of commands.

Installation & First Use 
$ cargo install --path . --locked --bin releaseweave
$ releaseweave init
$ releaseweave create
$ releaseweave list
$ releaseweave bump
